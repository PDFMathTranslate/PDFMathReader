# 降低资源占用

设置中的“降低资源占用”默认启用，旧设置文件自动补入默认值；关闭状态会持久化并同步到其他窗口。

## 检查结果与实现

| 状态           | 原有行为 / 问题                                                     | 当前策略                                                                                                             |
| -------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 窗口最小化     | 停止绘制，但保留位图与定时任务                                      | 立即暂停绘制、动画、阅读模式的新翻译调度、性能采样和周期阅读位置保存；一秒后释放页面和缩略图位图以及 64 MiB 位图缓存 |
| 应用非前台     | 原来的原生状态只判断窗口可见性，没有判断焦点                        | 监听 focus / blur，执行相同后台策略；返回前台重建页面和缩略图，保持阅读位置                                          |
| 翻译内核未工作 | Python 翻译内核按任务启动，任务完成后退出，没有常驻 Python 模型服务 | 保持按需启动；降低正常使用时性能采样频率，避免空闲阅读时每秒多次查询所有进程                                         |

完整文档翻译仍可在后台继续。已经发出的翻译请求允许完成，不通过强制终止进程节省资源。关闭开关会恢复渲染器后台绘制和调度；Electron 自身的后台节流仍适用。

页面内容、批注和磁盘翻译缓存不因位图回收丢失。回到前台会发生一次重新绘制。应用与后端、PDF 数据仍驻留，因此不能将位图归零解释为总内存归零。

## 验证

- `npm run build`：通过。
- `npm test`：34 项通过（包括设置升级、默认启用、类型检查、关闭状态持久化）。
- `./node_modules/.bin/electron . --smoke-test=resource-usage`：通过最小化回收、恢复绘制、非前台暂停、关闭和重新启用开关、阅读页码保持检查。
- 示例运行：页面 / 缩略图位图 40,555,816 bytes，缓存 40,238,376 bytes；后台两项均为 0。数值是画布分配量，不是进程 RSS 或实际 CPU 降幅。
