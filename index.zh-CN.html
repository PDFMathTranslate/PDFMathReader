使用要求与实验功能

翻译需要可用的服务及网络；部分服务可能产生 API 费用。Fast 与 Precise 需要通过 uv 安装相应内核。复杂版面可能影响排版还原效果，平台与服务的支持情况请参阅项目文档。

实验功能包括段落续接检测、本地生成目录，以及可选的远程 zotero-pdf2zh 服务。远程 Precise 服务需要自行部署，不随应用提供；没有文本层的扫描文档需要相应 OCR 支持。
