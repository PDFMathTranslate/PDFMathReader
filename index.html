Installation guide ↗

A separate app with a familiar desktop-inspired design.

Requirements and experimental features

Translation needs an available service and network access; some providers may charge API fees. Fast and Precise require their kernels to be installed through uv. Complex layouts can affect typesetting fidelity. See the project documentation for platform and service support.

Experimental features include paragraph continuation detection, local table-of-contents generation, and an optional remote zotero-pdf2zh server. The remote Precise server must be deployed separately and is not bundled. Scanned documents without a text layer need appropriate OCR support.
